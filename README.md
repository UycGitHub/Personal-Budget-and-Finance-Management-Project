# Personal Budget and Finance Management Project

## Overview

This project is designed to help individuals manage their personal finances effectively by tracking their income and expenses. By leveraging **Power BI** and **Excel**, the project enables users to visualize financial trends, identify spending patterns, and make data-driven financial decisions.

Key features of the project include:
- 💰 **Income Tracking** – Understand sources of income and monthly earnings.
- 📉 **Expense Management** – Categorize and analyze spending habits.
- 📊 **Financial Insights** – Gain a clear overview of financial health through interactive dashboards.

## Problem Statement

Many individuals struggle to track their financial health due to a lack of visibility into their income and expenses. Without structured tracking, it becomes difficult to:

- Identify areas where they overspend.
- Plan savings and manage budgets effectively.
- Detect financial mistakes and optimize expenses.

This project addresses these challenges by offering a **Power BI dashboard** that consolidates financial data into meaningful insights. Users can manually input their financial data into an Excel sheet and leverage **interactive analytics** to monitor and control their financial situation.

## Data Description

The project utilizes the **"Finance Database.xlsx"** file, following a **"Bring Your Own Data"** approach, where users enter their own financial information. The dataset structure includes:

- **Type**: Categorization of data into different financial aspects (e.g., Income, Expenses, Savings).
- **Component**: Further breakdown within each category.
- **Monthly Breakdown**: Each column represents a month in a year for tracking purposes.

### Data Input & Update Frequency
- Users manually input their financial data into the provided Excel template.
- The dashboard dynamically updates based on the input data.

## Methodology

### Tools Used
- **Power BI** – For interactive financial visualizations.
- **Excel** – For structured financial data entry.

### Data Processing Steps
1. **User Data Entry** – Users enter income and expenses in the provided Excel template.
2. **Data Import into Power BI** – The Excel file is loaded into Power BI for visualization.
3. **Visualization & Analysis** – Key metrics and trends are displayed in interactive dashboards.
